# Pitch deck

Static reveal.js deck: no build step. Open `index.html`, or host on GitHub Pages
(Settings → Pages → Deploy from branch → `/ (root)`).

## Edit
- `js/config.js`: product name, tagline, logo path, prices, demo video, team, grant split
- `assets/logo.svg`: replace with your logo (or point `logo` in config to another file)
- `assets/demo.mp4` (+ optional `assets/demo.jpg` poster): demo recording; the placeholder disappears automatically

## Present
- `→` / `Space` next · `S` speaker notes · `F` fullscreen · `Esc` overview
- PDF backup: open `index.html?print-pdf` in Chrome → Print → Save as PDF
